asyncio — Cooperative Concurrency
Core Concepts
Event loop: single thread, tasks interleave at await points
async def: coroutine function — returns coroutine object when called
await expr: suspend coroutine until expr completes
asyncio.run(coro): entry point for top-level coroutine
asyncio.create_task(coro): schedule coroutine to run concurrently
asyncio.gather(*coros): run multiple coroutines, collect results
asyncio.wait_for(coro, timeout=5): timeout individual coroutine
async for, async with: async iteration and context managers
asyncio.Queue: async producer-consumer pattern
asyncio.Semaphore: limit concurrent coroutines
asyncio.Event, asyncio.Lock: synchronization primitives
threading vs multiprocessing vs asyncio
asyncio: best for I/O-bound — network, DB, file — single thread
threading: I/O-bound with blocking libraries — GIL limits CPU work
multiprocessing: CPU-bound — bypasses GIL with separate processes
concurrent.futures: ThreadPoolExecutor, ProcessPoolExecutor
asyncio.run_in_executor(): run blocking code in thread pool from async context
