MODULE 06

MCP Integration

Connect Claude Code to GitHub, Jira, databases, Slack, and hundreds of external services using the Model Context Protocol (MCP).

📖 ~30 min 🔌 External integrations

What is MCP?

The Model Context Protocol (MCP) is an open standard that allows Claude Code to communicate with external tools and services. Think of it as a universal adapter — like USB-C for AI applications.

When you connect an MCP server, Claude gains new tools with names like mcp__github__create_pr or mcp__jira__get_issue. These work just like built-in tools — Claude can decide to use them as part of completing your tasks.

The MCP Flow
You: "Read ticket PROJ-123, implement it, then update its status to In Review"

Claude Code ─── mcp__jira__get_issue("PROJ-123") ──→ Jira
         ←── { title, description, acceptance criteria } ──

Claude Code ─── Read, Write, Edit (local files) ──→ Your Codebase

Claude Code ─── mcp__github__create_pull_request(...) ──→ GitHub
         ←── { pr_url: "github.com/org/repo/pull/47" } ──

Claude Code ─── mcp__jira__update_issue("PROJ-123", "In Review") ──→ Jira

Done! Feature implemented and ticket updated automatically.

Adding MCP Servers

The claude mcp add Command

bash — Adding MCP servers
# Syntax
claude mcp add <server-name> [options] -- <command> [args]

# Add GitHub MCP server
claude mcp add github \
  -e GITHUB_PERSONAL_ACCESS_TOKEN=ghp_yourtoken \
  -- npx -y @modelcontextprotocol/server-github

# Add with user scope (personal, not project)
claude mcp add github -s user \
  -e GITHUB_PERSONAL_ACCESS_TOKEN=ghp_yourtoken \
  -- npx -y @modelcontextprotocol/server-github

# Verify servers are configured
claude mcp list
  github    stdio  npx -y @modelcontextprotocol/server-github
  filesystem  stdio  npx -y @modelcontextprotocol/server-filesystem /projects
ScopeFlagStored InShared
Project (default)(none).mcp.json in project root✅ Commit to git
User-s user~/.claude/settings.json❌ Personal only
⚠️
Never Commit Tokens

Use environment variables (-e KEY=${KEY}) instead of hardcoded values. The token value is read from your shell environment at runtime, not stored in the config file.

The .mcp.json Configuration File

MCP server configuration is stored in .mcp.json at your project root. This file can be committed to git so your whole team gets the same integrations (without their personal tokens).

json — .mcp.json (safe to commit)
{
  "mcpServers": {
    "github": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "${GITHUB_TOKEN}"
      }
    },
    "jira": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@anthropic/mcp-jira"],
      "env": {
        "JIRA_HOST": "${JIRA_HOST}",
        "JIRA_EMAIL": "${JIRA_EMAIL}",
        "JIRA_API_TOKEN": "${JIRA_API_TOKEN}"
      }
    },
    "playwright": {
      "type": "stdio",
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}

Real-World: Ticket-to-PR Workflow

With GitHub + Jira MCP servers connected, you can automate an entire feature development cycle.

markdown — .claude/commands/ticket.md
---
description: Implement a Jira ticket end-to-end
allowed-tools: Read, Write, Edit, Bash(git *), Glob, Grep,
               mcp__jira__get_issue, mcp__jira__update_issue,
               mcp__github__create_pull_request, mcp__github__create_branch
argument-hint: <TICKET-ID>
---

Implement Jira ticket $ARGUMENTS end-to-end:

1. **Read the ticket**: Use mcp__jira__get_issue to fetch TICKET-$ARGUMENTS
2. **Understand requirements**: Read acceptance criteria carefully
3. **Create branch**: Name it after the ticket (e.g., feat/$ARGUMENTS-description)
4. **Search codebase**: Find relevant files using Grep and Glob
5. **Implement**: Write the code following CLAUDE.md conventions
6. **Write tests**: Add tests that verify acceptance criteria
7. **Run tests**: `npm test` — fix any failures
8. **Commit**: Using conventional commit format referencing $ARGUMENTS
9. **Create PR**: Use mcp__github__create_pull_request with:
   - Title: "[TICKET-$ARGUMENTS] {description}"
   - Body: Summary, changes, testing instructions
10. **Update Jira**: Set ticket status to "In Review" via mcp__jira__update_issue
Terminal — Using the workflow
You: /ticket PROJ-247

Claude: Fetching PROJ-247 from Jira...

  Reading src/styles/theme.css...

Database Integration Example

Connect a PostgreSQL MCP server to let Claude query and analyze your database directly.

bash — Add PostgreSQL MCP
claude mcp add postgres \
  -e DATABASE_URL="${DATABASE_URL}" \
  -- npx -y @modelcontextprotocol/server-postgres
Terminal — Database tasks
You: Find the 10 most expensive queries in the last 24 hours and
     suggest index improvements

URL-Based MCP Servers (HTTP/SSE)

Some MCP servers run as HTTP services rather than local processes. Add them with the URL type.

json — URL-based MCP in .mcp.json
{
  "mcpServers": {
    "my-api-server": {
      "type": "url",
      "url": "https://mcp.my-service.com/sse",
      "headers": {
        "Authorization": "Bearer ${API_TOKEN}"
      }
    }
  }
}
