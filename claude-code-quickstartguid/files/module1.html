MODULE 01

What is Claude Code?

Understand the agentic architecture, mental model, and capabilities that make Claude Code fundamentally different from traditional coding assistants.

📖 Reading time: ~15 min 🎯 Foundation module

The Core Idea

Claude Code is an agentic coding tool that runs in your terminal. Unlike a chatbot or autocomplete engine, Claude Code is designed to actively work on your codebase — reading files, writing code, running commands, managing git, and interacting with external services — all through natural language.

The key distinction is agency: Claude Code doesn't just suggest; it executes.

💬
Traditional AI Chat
You copy code snippets back and forth. You run commands yourself. Context is lost between sessions. It's a lookup tool.
🤖
Claude Code (Agentic)
Claude reads your actual files, makes changes, runs tests, creates PRs, and maintains context. It's a teammate.

How it Works — The Architecture

Claude Code is a loop: you give it a task, it plans steps, executes tools, observes results, and repeats until done. Understanding this loop is key to using it well.

The Agent Loop
You: "Add input validation to the registration form"

Claude Code loop:
  1. Plan  → "I'll need to read the form component,
              understand existing validation, add rules"
  2. Tool  → Read(src/components/RegisterForm.tsx)
  3. Observe → [reads file content]
  4. Plan  → "I'll add Zod schema validation"
  5. Tool  → Write(src/components/RegisterForm.tsx, ...)
  6. Tool  → Bash("npm test -- --testPathPattern=register")
  7. Observe → ✓ 8 tests passed
  8. Done  → "I've added validation for email, password
              strength, and username uniqueness."

What Claude Code Can Do

Development Tasks

  • Implement features end-to-end across multiple files and directories
  • Write unit, integration, and e2e tests for new or existing code
  • Refactor code with confidence — it reads first, then changes
  • Debug complex issues by reading error logs, tracing through code, and testing fixes
  • Add documentation, JSDoc comments, and inline explanations
  • Migrate between frameworks, languages, or architectural patterns

Git & DevOps

  • Create descriptive commit messages following Conventional Commits
  • Manage branches, merges, and cherry-picks
  • Review diffs and write PR descriptions
  • Resolve merge conflicts
  • Set up CI/CD pipeline configurations

Codebase Understanding

  • Explain unfamiliar codebases by reading and summarizing structure
  • Answer "where is X implemented?" by searching across all files
  • Map dependencies and architecture
  • Identify security vulnerabilities and code smells
💡
Pro Insight: Treat it as a Teammate

The best mental model for Claude Code is a skilled developer on your team who has just joined. Give them context (CLAUDE.md), clear tasks, and let them work. Review their output, correct misunderstandings, and iterate.

Limitations & What to Expect

Understanding limitations helps you work with Claude Code more effectively.

⚠️
Context Window Limits

Claude Code has a context window. Very large codebases can't be fully loaded at once. It searches intelligently, but you may need to guide it to the right files for complex cross-cutting changes.

⚠️
It Makes Mistakes

Always review Claude's changes before committing. Use git diff frequently. Claude Code is powerful but not infallible — treat it like a PR from a colleague you trust but still review.

⚠️
Training Data Cutoff

Claude may have outdated knowledge of very new libraries. Use WebFetch to load live documentation, or add library docs to your CLAUDE.md.

Access & Pricing

Claude Code requires a paid Anthropic account. There are two main ways to access it:

PlanBest ForNotes
Claude Pro Individual developers, getting started Monthly usage limits apply
Claude Max Heavy daily use Higher limits, priority access, more economical for frequent users
API Key Pay-as-you-go, CI/CD, automation Costs depend on model and usage; good for variable workloads
ℹ️
Which Plan Should I Choose?

Start with Claude Pro to evaluate your usage patterns. If you find yourself hitting limits daily, Claude Max is typically more cost-effective for power users. API key billing works best for automation and CI/CD pipelines where usage is sporadic.
