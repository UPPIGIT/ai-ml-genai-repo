MODULE 02

Installation & Setup

Install Claude Code on any platform, authenticate your account, verify the setup, and configure your environment for productive use.

📖 ~20 min 🔧 Hands-on setup

System Requirements

ComponentRequirement
macOSmacOS 10.15 (Catalina) or later
LinuxUbuntu 20.04+, Debian, Fedora, or similar
WindowsWindows 10+ with Git for Windows or WSL 2
NetworkInternet connection required
ShellBash, Zsh, Fish, PowerShell, or CMD
AccountClaude Pro, Max subscription, or Anthropic API key
ℹ️
Native Installer (Recommended)

The native installer is the recommended method. It requires no Node.js, installs faster, and auto-updates in the background. The older npm-based install is deprecated.

Install on macOS / Linux

The native installer uses a single curl command. This is the fastest and simplest method.

  1. Run the native installer
    bash
    curl -fsSL https://claude.ai/install.sh | bash

    This downloads and installs the claude binary and adds it to your PATH.

  2. Verify the installation
    bash
    claude --version
# Expected output: something like
# claude 2.x.x (native)
  3. Navigate to your project and launch
    bash
    cd ~/my-project
claude
# First run opens a browser for authentication

Homebrew (Alternative for macOS)

bash
brew install claude-code

# Homebrew does NOT auto-update. Run this periodically:
brew upgrade claude-code
brew cleanup claude-code  # Reclaim disk space from old versions

Alpine Linux / musl-based Distros

bash
# Install required dependencies first
apk add libgcc libstdc++ ripgrep

# Then set the flag and install
USE_BUILTIN_RIPGREP=0 curl -fsSL https://claude.ai/install.sh | bash

Install on Windows

Windows users have two options. Option 1 (Native) is now recommended and doesn't require WSL.

Option 1: Native Windows (Recommended)

  1. Install Git for Windows

    Download from git-scm.com. Git Bash is used internally by Claude Code.

  2. Install via PowerShell or CMD
    PowerShell
    # No need to run as Administrator
winget install Anthropic.ClaudeCode

# Or via PowerShell script (if winget unavailable):
iwr -useb https://claude.ai/install.ps1 | iex
  3. Verify
    PowerShell
    claude --version

Option 2: WSL (Windows Subsystem for Linux)

💡
WSL 2 Recommended

WSL 2 supports sandboxing for enhanced security. WSL 1 is supported but does not support sandboxing. Use WSL 2 for production workflows.

  1. Install WSL (PowerShell as Administrator)
    PowerShell (Admin)
    wsl --install -d Ubuntu
# Restart when prompted
  2. Inside your Ubuntu/WSL terminal, install Claude Code
    WSL bash
    curl -fsSL https://claude.ai/install.sh | bash
claude --version
⚠️
WSL Users: Run From Linux Terminal

Always launch Claude Code from your Linux/WSL terminal, not from Windows Command Prompt. Your project files should be inside the WSL filesystem (~/projects/) for best performance.

Authentication

Claude Code supports multiple authentication methods. Choose the one matching your account type.

Method 1: Claude.ai Subscription (OAuth)

If you have Claude Pro or Max, this is the simplest method.

  1. Run claude in your terminal

    On first launch, it opens your browser and asks you to log in with your Claude.ai account.

  2. Authorize in the browser

    Click "Authorize" when prompted. You'll be redirected back and your terminal session will begin.

Method 2: API Key

For API key access (pay-as-you-go or CI/CD pipelines):

bash — Shell profile (~/.bashrc or ~/.zshrc)
# Add your API key to your shell profile for persistence
export ANTHROPIC_API_KEY="sk-ant-..."

# Reload the profile
source ~/.zshrc

# Or set it inline for a single session
ANTHROPIC_API_KEY="sk-ant-..." claude
⚠️
Never commit API keys to git

Always use environment variables or a secrets manager. Add .env to your .gitignore. Consider using tools like direnv to manage per-project environment variables safely.

Migrating from npm

If you previously installed via npm, here's how to migrate to the native installer:

bash
# 1. Install the native binary
curl -fsSL https://claude.ai/install.sh | bash

# 2. Remove the old npm version
npm uninstall -g @anthropic-ai/claude-code

# 3. Verify (your ~/.claude config is preserved)
claude --version

IDE Integration

Claude Code works great alongside your IDE. You can keep Claude Code in a terminal pane while coding in VS Code, JetBrains, or any other editor.

VS Code Terminal Integration

  1. Open VS Code's integrated terminal

    Press Ctrl+` (or Cmd+` on Mac) to open the terminal panel.

  2. Launch Claude Code

    Type claude in the terminal. Claude Code can now see and edit all files in your VS Code workspace. Changes it makes appear immediately in your editor.

GitHub / GitLab Integration

Claude Code can be tagged in GitHub issues and PRs using @claude. This is configured separately via the Anthropic console — see the official docs for the latest setup instructions.

Desktop App

Prefer a graphical interface? Anthropic offers a Desktop app (macOS and Windows) that provides Claude Code without needing to use the terminal directly. It includes the same full feature set.
