Non-Negotiable Rules
The Golden Rules
01
Always launch from project root. Never from a subfolder — Claude needs the full file tree.
02
Run /init first, then edit. Bootstrap CLAUDE.md automatically, then add what Claude missed.
03
CLAUDE.md under 200 lines. Long context = diluted attention. Prune stale info aggressively.
04
Plan Mode before complex tasks. Read the plan. Correct misunderstandings before any code is written.
05
One feature per session. Start fresh. Cross-task context contamination kills quality.
06
Commit after every working milestone. Small commits = safe rollback points. Don't batch everything.
07
Deny Read:.env* in permissions. Claude must never read secrets. No exceptions.
08
Esc Esc at the first sign of trouble. Rewind early. Don't let Claude continue down a wrong path.
09
PostToolUse hooks for quality gates. Auto-run lint + type check + tests after every file write.
10
Use @filename not descriptions. "Fix @src/auth.py" beats "fix the authentication file".
11
State constraints explicitly. "Don't modify the payments module" is as important as what you want.
12
Commit CLAUDE.md to Git. Every teammate gets the same session context automatically.
